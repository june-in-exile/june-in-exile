#### ✨ Key Projects

* **[Octopus](https://github.com/june-in-exile/Octopus)** — 🏆 *Sui track, Vibe Sui Spring Fest 2026*
    * A decentralized privacy protocol on Sui: anonymous transfers plus shielded swaps, staking, and lending — built on ZK-SNARKs, Merkle trees, and Poseidon hashing.
    * Live at **[sui-octopus.com](https://www.sui-octopus.com/)** · [demo video](https://youtu.be/yxI9iaOocq0)
* **[zkWill](https://github.com/june-in-exile/zkWill)** — ZK-based digital will system
    * Compatible with Taiwan's sealed will framework. Published in **[Electronics 2026, 15(8), 1642](https://doi.org/10.3390/electronics15081642)**.
* **Optimized Cryptographic Circuits (Circom)**
    * **[AES-256-GCM](https://github.com/june-in-exile/aes256-gcm-circom)** — the first Circom circuit to support 128/192/256-bit AES-GCM.
    * **[Keccak256](https://github.com/june-in-exile/keccak256-circom)** — built at the **theoretical-minimum** constraint count.
* **[payLock](https://github.com/june-in-exile/payLock)** — 🏆 *Best Project, Changsha HOH Hacker House*
    * A Sui SDK for secure paid data unlocking, built on Walrus and Seal.
* **[Invoice-RWA](https://github.com/june-in-exile/Invoice-RWA)** — 🏆 *Oasis track, RWA Hackathon Taiwan*
    * A secure invoice lottery on Zircuit, using ROFL (TEE) to guarantee the integrity of results.
