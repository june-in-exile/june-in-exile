* **[Octopus](https://github.com/june-in-exile/Octopus)** — 🏆 *Sui track, Vibe Sui Spring Fest 2026*

    * Integrates IPFS, smart contracts, and cryptographic access control; compatible with Taiwan's sealed will framework. Published in **[Electronics 2026, 15(8), 1642](https://doi.org/10.3390/electronics15081642)**.
* **Optimized Cryptographic Circuits (Circom)**

    * **[Keccak256](https://github.com/june-in-exile/keccak256-circom)** — built at the **theoretical-minimum** constraint count.
* **[payLock](https://github.com/june-in-exile/payLock)** — 🏆 *Best Project, Changsha HOH Hacker House*
    * A Sui SDK for secure paid data unlocking, built on Walrus and Seal.
* **[Invoice-RWA](https://github.com/june-in-exile/Invoice-RWA)** — 🏆 *Oasis track, RWA Hackathon Taiwan*
